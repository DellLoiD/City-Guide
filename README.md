# City-Guide
Прототип гида по городу с использованием GPT
## Задача:

Получить опыт в построении RAG системы котораяотвечает  на  вопросы с учетом предоставленного внешнего документа.

## Что сделано:

Выбрана тематика: Информация о городе/гид по городу.

Из документа извлечен и очищен текст, использована модель openai/gpt-3.5-turbo-0125 для поиска информации по  тексту.

Построен граф по pdf документуиз уникальных слов и их зависимостей.

## Результат:

Получил корректные ответыпо pdf документу. Сравнил ответы от неросети с  построением графа и без. С графом  ответ лаконичнее и больше  основывается на самом документе.
